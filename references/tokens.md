# 色彩与材质

## 色彩 Token

```css
:root {
  --canvas: #F8F7F3;
  --blue-100: #DCEBFF;
  --blue-700: #294A91;
  --pink-100: #FFE0EC;
  --pink-500: #F08AB7;
  --frame: #C6C8CD;
  --frame-shadow: #5B606A;
  --ink: #1E2635;
  --paper: #FFFFFF;
}
```

| Token | 用途 | 不要用于 |
| --- | --- | --- |
| `--canvas` | 暖白主背景 | 窗口外壳 |
| `--blue-100` | 粉雾蓝底色、安静填充 | 大段正文文字 |
| `--blue-700` | 标题栏、主状态、重点操作 | 整页深色外框 |
| `--pink-100` | 柔和提示、次要区域 | 强行动作的唯一信号 |
| `--pink-500` | 激活态、进度、关键词 | 大面积页面底色 |
| `--frame` | 窗口材质 | 页面外圈或卡片堆叠 |
| `--frame-shadow` | 1px 结构阴影 | 柔软的大面积投影 |
| `--ink` | 正文、图标、线条 | 大面积填充 |
| `--paper` | 阅读内容面 | 无结构的纯白留白墙 |

## 背景

用低对比度点阵、渐变点阵或马赛克网格建立空气感。蓝色和粉色是独立信号；它们之间的渐变可以出现在底图纹理、转场面或明确选择的窗口外观中，但必须柔和经过中间色，不能抢走标题或承担正文重点。

```css
.dot-field {
  background:
    radial-gradient(circle at 18% 16%, rgb(240 138 183 / 24%), transparent 22rem),
    radial-gradient(circle at 82% 76%, rgb(41 74 145 / 16%), transparent 26rem),
    radial-gradient(rgb(41 74 145 / 12%) 1px, transparent 1px) 0 0 / 16px 16px,
    var(--canvas);
}
```

## 色彩与层级分配

- **深蓝**：一屏默认只承担主窗口标题栏和一个“当前状态”。不要同时把多个内容卡、结果块和按钮都填成深蓝。
- **粉色**：用在当前路径、重点词、推荐项和标记；它可以让画面活跃，但不替代正文背景。
- **灰色**：主窗口用灰色立体外框；次级内容可以用平面灰色标题栏或细灰线，不必再复制主窗口机壳。
- **蓝粉渐变**：只用于空气层、转场面或可选窗口外观。必须从编辑蓝经过低饱和中间色柔和进入信号粉，至少使用四段色阶；禁止在中点硬切成两块颜色。
- **阴影**：主窗口可以有机械式右下投影；次级窗口需要机身感时，可用低饱和蓝/粉环境影加内高光。不要用硬灰投影，也不要让每个元素都浮起。

## 窗口机身 Token

- 最大窗口以约 `4px` 的灰色机身边缘、轻内高光和低强度右下结构影为基准。它应像复古软件窗口，而不是厚重相框。
- 最大窗口与窗口层级示例必须共用同一组边框与阴影 Token；不能一处很薄、另一处突然变成厚相框。
- 中间与小窗口逐级减轻边框和阴影，不复制最大窗口的重量。

## 材质门槛

- **窗口灰**：用亮边、内阴影和单层深色结构线体现机械感。主窗口的灰色外框内部嵌入编辑蓝标题栏；不要在窗口以外再增加第二圈灰色大边框。
- **语义工具 3D**：使用有圆润高光、透明边缘和统一投影的文件夹、光标或磁盘；每件物件必须对应收集、选择或保存动作，不使用无意义的抽象软塑料块。
- **灰银金属语汇**：星体用于转折或关键结论；光标用于选择／判断；轨道环用于连接关系；心形吊饰用于轻量反应；回形针用于引用或补充。默认只用银灰单色材质，必须有体积、环境反射、明确的高光路径和足够留白。不要混入粉色、蓝色、彩虹反光或贴纸式高光。每件物件都要有用途，不能只是填空装饰。
- **CRT**：只在旧屏幕、素材比较或转场局部使用；主正文面保持干净。
