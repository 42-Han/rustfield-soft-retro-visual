# 场景规范：小红书图文卡片（3:4）

## 触发

用户说“做小红书图文”“做 3:4 图文”“文章转卡片”“做图文封面”“1080×1440 卡片”时使用。

## 固定规格

| 项目 | 规则 |
| --- | --- |
| 单页尺寸 | 1080×1440px |
| 典型张数 | 5–10 张；最多 18 张 |
| 文件 | 一个 HTML 包含所有 `.card` |
| 预览 | 页面可滚动查看，也能切换当前卡片 |
| 导出 | 当前页 PNG + 全部页面 PNG/ZIP（本地依赖可用时） |
| 内容 | 封面 → 观点/步骤 → 证据/示例 → 结论/关注 |

## 卡片职责

### 封面

- 一个大标题、一个副标题或短句、作者识别。
- 允许使用完整灰色复古窗口作为系列记忆点。
- 标题 72–96px；关键词只标一次粉色或蓝色。

### 内容页

- 每页只表达一个小观点。
- 可轮换使用：编号编辑页、左右对照、流程轨道、证据放大、图文分栏、金句留白、数据叙事。
- 正文建议 32–42px；辅助说明 24–30px。
- 图片要大且完整，不能被装饰物遮挡。

### 尾页

- 一句可记住的结论、黑猫头像或签名、关注动作。
- 标签最多 2–4 个，做成独立圆角贴纸，不拉成横向栏。

## 断行规则

- 中文标题在生成时显式插入 `<br>`，按语义单元断开。
- 英文、数字、模型名和产品名使用完整 span，不断词。
- 不能留下一个孤字、孤标点或“看似空白但实际拥挤”的最后一行。

## 视觉变化

- 连续三张卡片不得使用完全相同的版式。
- 粉蓝灰是同一套系统，不要求每页都同时出现三色。
- 3D 物件只在解释工具、指向证据或建立品牌记忆时出现；导出画面不能出现动画残影。

## 交付检查

- 每页尺寸精确为 1080×1440。
- 标题、正文和图片在手机缩略图中仍有清晰层级。
- 主要图片没有被文字、星标、光标或边框遮挡。
- 导出按钮失败时不影响预览和手动截图。
- `prefers-reduced-motion` 下内容仍显示最终状态。
