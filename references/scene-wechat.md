# 场景规范：公众号文章排版

## 触发

用户说“写公众号”“公众号排版”“微信文章”“把文章排版好”“一鱼多吃”“生成可复制文章”时使用。

## 编辑器约束

- 内容最大宽度 677px，底色使用 Rustfield 暖白。
- 复制产物优先使用 `<section>`、`<p>`、`<span>`、`<img>` 和少量 `<br>`。
- 所有样式写在 `style` 属性中；不能依赖 `<style>`、class、外部 CSS 或 JavaScript。
- 不使用 `div`、`figure`、`figcaption`、`article`、`main` 等包装标签作为复制产物。
- 图片复制版应支持 base64；预览版可以使用相对路径。

## 页面结构

```text
文章阅读面
  ├─ 顶部 kicker
  ├─ 主标题（显式语义断行）
  ├─ 引言金句
  ├─ 粉蓝灰短分隔条
  ├─ 引言区块
  ├─ 章节 × N：英文装饰词 + 中文标题 + 重点条 + 正文/图片
  ├─ 章节分隔条
  ├─ 结尾金句
  └─ Rustfield 签名档
```

## 内容映射

| 输入 | 输出 |
| --- | --- |
| `# 标题` | 主标题 |
| `## 标题` | 章节头三件套 |
| `### 标题` | 小标题 |
| `**重点**` | 粉色荧光笔高亮 |
| `> 引用` | 引言区块 |
| `---` | 粉蓝灰分隔条 |
| 图片语法 | 图片 + 可选图注 |
| 普通段落 | 18px 正文，line-height 2 |

## 标题协议

- 不让浏览器自行决定主标题的语义换行。
- 中文超过一行时，在标点、转折或完整短语后插入 `<br>`。
- 英文、数字、产品名、模型名不能断开。
- 主标题默认不超过两行；如果超过，先重写标题结构，再缩字号，最后才增加一行。

## Rustfield 文章气质

- 文章比横向演示更克制，不把每段内容包装成窗口。
- 粉色只标记判断或重点；蓝色用于章节结构和链接；灰色只在证据框或小型窗口中出现。
- 黑猫插图只在概念解释或关键章节出现，不作为每节固定头像。
- 文字沿用原稿，除非用户明确要求改写；版式可以重组，观点不擅自增加。

## 交付检查

- 复制片段没有 `div`、`style`、class、外部 CSS 或 JS。
- 文章宽度、正文字号、行高、标题断行和图片尺寸符合规范。
- 没有孤字、断词、空 section 或默认 HTML 样式。
- 预览版与复制版的内容顺序一致。
