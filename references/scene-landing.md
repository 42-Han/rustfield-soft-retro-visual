# 场景规范：Landing 与活动介绍页（16:9 / 网页）

## 目标

让访客快速理解 Rustfield 是谁、正在提供什么内容、为什么值得继续阅读或关注。

## 推荐结构

1. 不对称 Hero：一个主张 + 一个视觉或黑猫插图位。
2. 价值段：三项以内的内容方向，不做卡片墙。
3. 证据段：一个作品、案例、数字或过程片段。
4. 行动段：关注、查看教程、阅读文章或进入项目。

## 视觉规则

- 主窗口可以使用灰色机身套蓝色标题栏，次级内容尽量使用平面纸面和粉色标记。
- 每个 section 换一种信息关系，但不为了“变化”而更换皮肤。
- CTA 用粉色或蓝色明确指向动作，不使用霓虹发光按钮。
- Hero 身份标记优先使用透明印章、细边圆章或小型贴纸，不用一整块粉色横幅抢主标题。
- 三项价值不要做成三个同重矩形卡片；优先用“编号节点 + 连接线 + 标题/说明”的 editorial 结构，让阅读顺序比装饰更清楚。
- 价值段必须有明确的进入顺序：设计 → 方法 → 实验，箭头或线只承担这个关系。
- 黑猫形象只放在 Hero 或需要角色解释的 section；不常驻每一屏。

## 禁忌

- 不做所有 section 居中的通用 Landing 模板。
- 不放五个以上的 CTA，不用“AI powered / future / magic”等空泛词作为主文案。
- 不用无意义的 3D 球体、渐变光环或悬浮贴图撑满首屏。
