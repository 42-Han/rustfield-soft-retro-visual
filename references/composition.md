# 版式与字体

## 四层页面语法

1. **底图**：暖白／粉雾蓝与低对比点阵。
2. **窗口**：一枚灰色复古窗口外壳。
3. **信息**：主标题、辅助说明、一个内容机制。
4. **点睛**：可选的一枚 3D 物件或材质效果。

默认阅读顺序：**标题 → 一句说明 → 内容机制 → 可选点睛。**

## 横向教程（16:9，优先）

- 主标题：64–76px，加粗，最多两行。
- 分区标题：38–48px，加粗。
- 正文：24–30px，每段最多三短行。
- 功能标签：16–18px，不能承担主信息。
- 中文大标题行高保持约 1.04–1.10，字距只做轻微收紧（约 `-0.02em` 至 `-0.05em`）；不要用极窄行高或过重负字距制造“挤在一坨”的效果。
- 横向播放页的字号应相对窗口容器而不是浏览器视口缩放；窗口有最大宽度时，字号也必须同步封顶，避免大屏上标题突然变大并产生意外换行。
- 内部安全边距：画面宽度的 6–8%。
- 内容机制：流程、对比、引用、演示四选一。

一屏回答一个问题。标题和机制放在同一个窗口中；点阵留在窗口外；点睛物不要压住标题或流程。

横向画面要保留呼吸：让图片、文字和点睛物分别占据明确区域，优先使用左右锚点与较大的组间距，不要把所有内容收进窗口中心。点睛物只能放在真正的留白区，并置于正文层下方。

主屏与横向教程的最大窗口，默认使用**有厚度的灰色金属外框**，并在内部嵌入标题栏和内容面。中间窗口可以从蓝、粉、灰、蓝粉渐变或灰色渐变中选择；小窗口可以只使用灰色、粉色或透明细框。颜色不强行绑定功能，但层级重量与文字对比必须稳定。

最大窗口的厚度应接近复古软件机身：约 4px 灰色斜面、轻内高光与低强度右下结构影。蓝粉渐变必须柔和经过中间色，不使用硬切双色块。

所有箭头都应占据节点之间的独立轨道。横向空间不足时，关系组件整体转为纵向；不能让连接线继续使用宽屏坐标而节点已经换行。

## 教程／知识网页

顺序：主张 → 核心解释 → 流程 → 示例 → 收束。窗口用于章节分组，不用于包住每段文字。正文优先可读、留白充足。

## 图文卡片与 PPT

只保留标题栏和内容面两层窗口语法。放大一个结论，不缩小整张教程界面。像素字体只用于非常短的状态标签，正文使用清晰的无衬线字体。
