# 场景规范：横向教程与演示（16:9）

## 适用

用于 AI、设计、产品和工具教程；横向视频演示；PPT 式单幕播放；需要观众跟上一个判断、步骤或证据的内容。

## 默认交付

- 画布：16:9，优先单幕播放。
- 结构：灰色立体窗口 → 蓝色内嵌标题栏 → 内容面 → 一个主要信息机制。
- 交互：点击当前画面、方向键、空格键切换场景；不要求连续滚动。
- 信息：一个主标题、一句说明、一个流程/决策/对比/证据/数据机制。
- 点睛物：0–1 个，只有在能指向内容时出现。

## 场景选择

| 内容关系 | 结构 |
| --- | --- |
| 让观众记住一个判断 | 主张焦点 |
| 连续步骤与当前进度 | 流程轨道 |
| 先问问题再分支 | 决策树 |
| 两种方案或前后变化 | 对比双窗 |
| 素材到结果的转换 | 输入输出台 |
| 解释一个截图局部 | 证据放大镜 |
| 解释趋势或比例 | 数据叙事 |

## 排版与动效

- 标题优先读完；中文不要因为 viewport 放大而意外断行。
- 标题可在语义边界显式换行，但不要留下孤字或把一句话拆成过多短行。
- 动效只承担进入、推进、聚焦、变化或气氛中的一个关系。
- 关闭动效后仍然完整可读；`prefers-reduced-motion` 时显示最终状态。

## 不做什么

- 不把教程做成 SaaS 仪表盘。
- 不把流程做成普通等宽表格。
- 不把解释性脚本、制作备注和“这里应该出现什么”暴露在最终演示内容里。
- 不用装饰物填补空白；先调整构图，再决定是否需要物件。
