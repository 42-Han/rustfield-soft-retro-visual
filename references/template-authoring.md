# 模板使用说明

## 从哪里开始

- 还不确定这页是什么结构：从 [16:9 起始模板](../templates/starter-16x9.html) 开始。
- 需要选择已有结构：打开 [模板导航](../templates/template-index.html)，按信息关系选择。
- 需要确认组件语法：打开 [组件图谱](../templates/component-atlas-16x9.html)。
- 已经有口播稿和配图：从 [16:9 起始模板](../templates/starter-16x9.html) 开始，按场景顺序替换标题、说明和素材；每一幕只使用一种信息关系。
- 需要制作小红书竖向图文：从 [3:4 卡片模板](../templates/cards-3x4.html) 开始，设计基准固定为 1080×1440。
- 需要制作公众号内容：从 [公众号文章模板](../templates/wechat-article.html) 开始，只复制生成的文章内容，不复制右侧编辑面板。
- 需要制作品牌入口：从 [Landing 模板](../templates/landing-16x9.html) 开始；需要工具型工作台时使用 [App 模板](../templates/app-16x9.html)。
- 需要完整浏览视觉规范：打开 [完整视觉手册](../templates/soft-retro-visual-handbook.html)，从上到下阅读颜色、层级、组件、动效和介质适配。

## 起始模板的替换顺序

1. 替换窗口标题栏中的场景名和集数。
2. 只写一个主标题；如果标题需要强调，只用一次粉色底线标记。
3. 用一两句辅助说明解释主标题，不把第二个观点塞进说明。
4. 把 `MECHANISM_SLOT` 替换成一个内容机制：流程、决策、对比、输入输出、证据或数据。
5. 需要点睛物时，只保留一个具有语义的素材位；没有明确作用就删除。
6. 根据 [动效配方](motion-recipes.md) 选择一个主动作，先确认静态状态再加动画。

## 交付前替换清单

- [ ] `RUSTFIELD_VISUAL / EPISODE_01` 已换成真实场景名。
- [ ] 主标题在 16:9 画面中可以一眼读完。
- [ ] 主要机制没有退化成普通表格或卡片墙。
- [ ] 粉色只承担重点、当前路径或关键标注。
- [ ] 深蓝没有填满次级窗口。
- [ ] 灰色只用于窗口的机身和边界。
- [ ] 点阵、CRT 和可选物件没有压住正文。
- [ ] 关闭动效后，页面仍然完整可读。

## 跨介质交付规则

| 介质 | 设计基准 | 必须保留 | 必须删除 |
|---|---:|---|---|
| 16:9 教程 / 演示 | 1920×1080 | 灰色窗口、蓝色标题栏、窗口控制符、一个内容机制 | 连续滚动式长页面、脚本说明、无语义点缀 |
| 小红书图文 | 1080×1440 | 单张主观点、粉色重点、清晰的页码或序列关系 | 细小注释、复杂窗口嵌套、导出后看不清的装饰 |
| 公众号文章 | 677px 阅读宽度 | 标题、导语、章节、引用、配图、结论 | 窗口外壳、交互按钮、脚本标签、外部 CSS 依赖 |
| Landing / App | 16:9 首屏 | 主行动或工作区关系、清晰导航、结构影 | 仪表盘噪音、无目的的卡片墙、过量深蓝 |

## 结构检查

完成模板后运行：

```bash
python3 scripts/validate_visual_templates.py
python3 scripts/inline-wechat-check.py /path/to/generated-wechat-fragment.html
```

第一个检查模板是否具备必要的格式标记、窗口结构、导出能力和动效降级；3:4 模板的 PNG 导出依赖已经放在 `assets/html2canvas.min.js`，不依赖 CDN。第二个只检查最终复制给公众号编辑器的 HTML 片段，不检查右侧预览工作台。
