# 动效与时间感

动效可以解释信息，也可以建立气氛和记忆点。判断标准是：看动效后，读者是否仍能立刻读到主标题和主要机制。

## 基础节奏

- 窗口整体进入：120–220ms，使用轻微位移和透明度变化，不拆成许多零散的组件动画。
- 文字：窗口落定后按阅读顺序出现，单项间隔 40–90ms。
- 流程：只高亮当前步骤，或让指针移动一次来完成引导。
- 所有页面保留静态可读状态，并提供 `prefers-reduced-motion`。

## 连续 3D 动效

允许持续漂浮、轻微弹跳和缓慢旋转。它们适用于小物件和高质量金属星体，而不是正文卡片。

- 漂浮：6–10 秒一个循环，垂直振幅 6–18px。
- 旋转：12–24 秒一个循环，角度 3–12°。
- 弹跳：采用柔和缓入缓出，避免每秒多次的机械跳动。
- 保持物件远离标题基线和主要文字；它要像有重量、在空气里缓慢运动，而不是吸引注意力的 GIF。

## 酸性金属与 CRT

- 金属物件默认使用单色银灰：星体用于转折，光标用于选择，轨道环用于连接，心形吊饰用于反应，回形针用于引用。可用慢速旋转、光线掠过和极弱的呼吸亮度表达材质；避免粉蓝渐变、硬闪、厚描边、镜面噪点和低分辨率反光。
- CRT 纹理只进入局部屏幕或过渡画面；用低透明度细线或噪点，不把它铺到正文层。
- 3:4 卡片默认不自动播放复杂动画；导出前以静态最终状态为准，必要时只保留 120–220ms 的入场。
- 公众号文章默认是静态阅读；动效只存在于原始网页预览，不进入最终可粘贴的文章片段。

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
  }
}
```
